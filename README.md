# Task-1-Data-Cleaning-Preprocessing


## Objective
To clean and preprocess a raw marketing campaign dataset using Python and Pandas.

## Dataset Used
Marketing Campaign Dataset

## Steps Performed
- Loaded dataset using Pandas
- Explored dataset structure and datatypes
- Checked missing values
- Filled missing values using median
- Removed duplicate records
- Converted date format into consistent format
- Standardized column names
- Checked data quality and outliers
- Cleaned categorical/text inconsistencies
- Saved cleaned dataset

## Tools Used
- Python
- Pandas
- Google Colab

## Outcome
Successfully cleaned and prepared the dataset for analysis and visualization.
